# Сlubhouse adaptive layout
Адаптивная верстка страницы Тишинский бульвар

## 🌐 Демо

[https://dariabesp.github.io/clubhouse-adaptive-layout/](https://dariabesp.github.io/clubhouse-adaptive-layout/)

## 🚀 Запуск проекта

1. Клонировать репозиторий:
```bash
git clone https://github.com/DariaBesp/clubhouse-adaptive-layout.git
```
2. Перейти в папку проекта
```bash
cd clubhouse-adaptive-layout
```

3. Запустить локально:
* через VS Code с установленным расширением Live Server:
нажмите правой кнопкой на index.html → Open with Live Server
